# التاريخ: 2026-10-06
# ملاحظة: الباتش ده فوق PATCH v8 مباشرة — لو ركبت v8 ركّب ده فوقه عادي
# (لو مش ركبت v8 لسه، ركّب الاتنين مع بعض — ملفاتهم مختلفة ما يتشاحنش)

## 🎯 الفكرة
لما قارنا تطبيقك بـ workeros: سرعته واستهلاكه الشبه صفر (3ms CPU) مصدره
معمارية: بياناته بتتسحب من المتصفح مباشرة لـ Supabase (يعني CPU خدمة تانية
مش كلاودفلير)، وأصوله الثابتة بتتخدم من CDN من غير ما تشغل الـ Worker أصلاً،
وبيكاشي الداتا في المتصفح (TanStack Query) فمفيش طلبات متكررة أصلاً.

تطبيقك (Next.js + Prisma جوة الـ Worker) معماريته مختلفة — فالحل العملي:
نقل فكرة "مفيش طلبات متكررة" لكاش الحافة. v8 كاشى الداشبورد والعملاء،
ودلوقتي v9 بكشّي **باقي الـ GETs الأتقل**:

| الـ API | قبل | بعد (كاش) | TTL |
|---|---|---|---|
| /api/products (كاشير/منتجات) | 562ms | **74ms** | 20 ثانية |
| /api/categories | 166ms | **38ms** | 60 ثانية |
| /api/suppliers | 43ms | **24ms** | 30 ثانية |

- الأرقام دي من المختبر على محاكاة موبايل — على الإنتاج الحقيقي الفرق أكبر
  (كل HIT = **صفر CPU تقريباً** من الـ Worker، زي workeros بالظبط)
- الكاش لكل محل منفصل، و**بيمسح نفسه فوراً** بعد أي إضافة/تعديل/حذف
  (منتج/تصنيف/مورد/فاتورة بيع لأن البيع بيخصم مخزون)
- البحث والفلترة والصفحات مش بتتكاش أصلاً — بتعدّي عادي للسيرفر
- مفتاح منتجات الكاش بيشمل فرع المستخدم (لو عندك فروع، كل فرع بيشوف
  قايمته الصحيحة)

## 📦 التركيب
1. انسخ الملفات السبعة بنفس المسارات فوق مشروعك
2. أعد البناء والنشر:
   bun run cf:build
   npx wrangler deploy

## ✅ الفحوصات (كلها عدت)
- login ✓ / كاش منتجات+تصنيفات+موردين ✓ / البحث مش متكاشي ✓
- إضافة تصنيف → ظهرت فوراً (مسح فوري) ✓ / الدايلوجات لسه لحظية ✓

## 💡 عشان توصل لاستهلاك workeros بالظبط (0 CPU)
1. **الباتشات دي** (v8+v9): أغلب الـ GETs المتكررة بقت صفر CPU
2. **Hyperdrive** (لو الترقية المدفوعة): بيقلل تكلفة اتصال قاعدة البيانات
   — db.ts عندك بيدعمه تلقائياً لو ضفت binding في wrangler.jsonc
3. **Workers Paid ($5/شهر)**: حد الـ CPU بيبقى 30 ثانية بدل 10ms —
   خطأ 1102 بيختفي نهائياً. دي أرخص وأضمن خطوة حقيقية
4. **على المدى الطويل**: نقل قراءة الداتا للمتصفح مباشرة (زي Supabase/
   Neon مع صلاحيات صف-by-صف) — دي إعادة هيكلة كبيرة، مش مستعجلة
