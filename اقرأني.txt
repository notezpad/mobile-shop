# الملفات المصلحة — الموارد البشرية
=====================================

كل الملفات بمساراتها الصح — انقلها لنفس المسارات في المشروع عندك وريستارت السيرفر.

## 1) إصلاح حساب الرواتب على الأيام الفعلية
(الموظف اللي محضرش ولا يوم = صافي صفر)

    src/lib/hr.ts                        → countPaidDays + computePayslip (منطق الحساب نفسه)
    src/lib/hr-payroll.ts                → توليد مسودة الرواتب بالأيام الفعلية
    src/app/api/hr/payroll/[id]/route.ts → عرض المسودة (أيام الشغل + الغياب + بدون تسجيل)

## 2) إعادة تصميم صفحات الموارد البشرية السبعة

    src/components/shop/hr/hr-ui.tsx           → نظام التصميم المشترك (هيرو + بانلات + شارات)
    src/components/shop/hr/HrHomeView.tsx      → الرئيسية
    src/components/shop/hr/HrAttendanceView.tsx → الحضور والانصراف
    src/components/shop/hr/HrLeavesView.tsx    → الإجازات والأذونات
    src/components/shop/hr/HrEvaluationsView.tsx → التقييمات
    src/components/shop/hr/HrAdvancesView.tsx  → السلف

## 3) حذف البانرات من صفحة الرواتب
(البانر الأصفر "اتخصموا من الصافي" + الأزرق "يوم متبقي" + تحذير نافذة الصرف)

    src/components/shop/hr/HrPayrollView.tsx   → الصفحة نضيفة: هيرو ← شهر ← إحصائيات ← جدول

## 4) ميزة تصفية حساب موظف بيمشي (جديدة كلياً)

    src/components/shop/hr/HrEmployeesView.tsx → زر التصفية + دايلوج المعاينة والصرف
    src/app/api/hr/employees/[id]/settle/route.ts → API التصفية (معاينة + تنفيذ ذرّي)

    الاستخدام: صفحة الموظفين → أيقونة اليد بفلوس جنب الموظف → تختار آخر يوم شغل
    → بيشوف كل الشهور غير المدفوعة + خصم باقي السلف بالكامل → تصرف → حسابه يتقفل.

## ملاحظات
- الملفات شغالة مع بعض — نزّلهم كلهم مرة واحدة.
- بعد النقل: npm run dev (أو ريستارت السيرفر).
- لو عندك تعديلات يدوية على أي ملف من دول، خد نسخة احتياطية قبل الاستبدال.
