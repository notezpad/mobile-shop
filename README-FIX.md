# إصلاح جذري: الاشتراك كان يتجدد بدون دفع (27 سبتمبر 2026)

## سبب المشكلة
عند الضغط على "ترقية الباقة" كان `/api/paymob/checkout` ينشئ سجل اشتراك
بحالة `pending` وتاريخ انتهاء = اليوم + 30 يوم (أو 365) **قبل الدفع**.
وكل الأماكن التي تقرأ "اشتراك المحل الحالي" كانت تأخذ أحدث سجل بدون
فلترة الحالة، فيتحول هذا السجل غير المدفوع إلى اشتراك فعّال 30 يوم.

## ما تم إصلاحه
1. `src/app/api/paymob/checkout/route.ts` — السجل المعلّق صار بمدة صفر،
   وإغلاق محاولات الدفع المهجورة الأقدم من 30 دقيقة.
2. `src/lib/subscription-status.ts` (جديد) — تعريف الحالات المعتبرة فقط
   (`active`, `expired`)؛ `pending`/`failed`/`cancelled` لا تمنح أي مدة.
3. `src/lib/auth.ts` — التحقق من صلاحية الاشتراك يتجاهل السجلات غير المدفوعة.
4. `src/app/api/subscription/route.ts` — صفحة الإعدادات تعرض الاشتراك الحقيقي فقط.
5. `src/app/api/subscription/start-trial/route.ts` — نفس الفلترة.
6. `src/app/api/paymob/webhook/route.ts` — المدة تُحسب فقط بعد تأكيد الدفع،
   وتُمدد من الاشتراك الفعّال الحقيقي، مع منع التفعيل المكرر (idempotency).

## خطوة مطلوبة بعد النشر (مرة واحدة)
تشغيل سكربت تنظيف السجلات الخاطئة الموجودة حالياً:
```
npx tsx prisma/fix-unpaid-pending-subscriptions.ts
```
