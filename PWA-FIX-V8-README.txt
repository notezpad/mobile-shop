صفحات المخزون الأربعة عندك (/inventory و /inventory/movements
و /inventory/transfers و /inventory/stocktake) بتقرأ من هوك البيانات
المشترك useInventoryData كده:

    const { products, branches, stats, reload, loadErrors } = useInventoryData()
    // وبعدها: loadErrors.products / .movements / .transfers / .stocktake
    // عشان تعرض بانر "تعذّر تحميل ..." مع زر إعادة المحاولة

لكن ملف useInventoryData.ts اللي اتبعت في حزم v6/v7 (من نسختنا القديمة)
كان بيرجّع كل حاجة **ما عدا** loadErrors! فـ loadErrors بتطلع undefined
وأول قراءة منها بتقع:

    undefined.products  ←  TypeError — فالصفحة الأربعة بتقع
    أونلاين وأوفلاين بنفس الطريقة (اتأكدنا من كودك المنشور نفسه:
    جبنا الـ chunks من nezampos.com وفككناها حرف بحرف).

الخلاصة: المشكلة مش من صفحاتك ولا من السيرفر — دي تعارض بين ملف
الهوك القديم اللي اتشحن قبل كده ونسخة الصفحات الأحدث عندك.
وحلّها: ملف واحد جديد بيرجّع كل اللي صفحاتك بتطلبه.
