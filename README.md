# تحديث v14 — إصلاح الشاشة السوداء + تجاوب المخزون 100%

## ماذا يصلح هذا التحديث؟

### 1) شاشة سوداء بعد فتح صفحة الحركات (أهم إصلاح)
المشكلة: الصفحة بتظهر شوية وبعدها شاشة سوداء فاضية — لأن التطبيق كله كان من غير أي
ErrorBoundary، فأي خطأ بسيط بيفضّي الشاشة بالكامل بدون أي رسالة.

الحل (3 طبقات حماية):
- **صفحة خطأ ودودة**: أي كراش في أي صفحة هيظهر كارت فيه زر «إعادة المحاولة» و
  «تحديث الصفحة بالكامل» بدل الشاشة السوداء — ملفات جديدة: `(shop)/error.tsx` و `global-error.tsx`.
- **حارس النسخة الجديدة (ChunkGuard)**: لو المتصفح ماسك نسخة قديمة من الصفحة بعد
  نشر تحديث جديد، بيكشف فشل تحميل الملفات ويعمل تحديث تلقائي مرة واحدة — ده السبب
  الأشهر لـ«بتظهر 3 ثواني وبعدها شاشة سوداء» بعد أي تحديث.
- **حرس أقسام**: لو الدفتر نفسه حصل فيه خطأ، الصفحة بتفضل شغالة ويظهر زر إعادة
  محاولة مكان الجزء المعطوب فقط.

### 2) كروت المخزون اللي كانت نصوصها مقطوعة بنقاط
كارت «إجمالي الأصناف» وكارت «قاربت على النفاذ» (والأربعة كلهم) — على الجوال بقى
النص بيلف بدل ما يتقص بنقاط، مع الحفاظ على نفس الشكل على الشاشات الكبيرة.

### 3) تصميم جديد لكروت المنتجات على الجوال (بستايل صفحة المخزون)
- التسمية **فوق** والقيمة **تحتها** (الأسلوب الصح) بدل ما كانت جنب بعض.
- السعر والتكلفة بيتفرضوا كاملين — مبالغ مليونية (1,250,000 جنيه وأكتر) من غير أي قص.
- اسم المنتج واسم الفرع بيلفوا بالكامل — مفيش نقاط قص خالص.
- الكمية ملونة حسب الحالة: أخضر (سليم) / برتقالي + «وصلت للحد الأدنى» / أحمر «نفدت».
- كروت بحواف دائرية وهوية ألوان صفحة المخزون، ومرتبة 2×2.

### 4) نفس معالجة الالتفاف لصفحات التحويلات والجرد والحركات
أسماء المنتجات والفروع في التحويلات والجرد ودفتر الحركات بقت بتفرد كاملة
بدل القص بنقاط.

## طريقة التركيب (مهم — كل الملفات)

انسخ محتوى مجلد `src` فوق مشروعك بحيث تستبدل/تضيف:

| الملف | الحالة |
|---|---|
| `src/app/global-error.tsx` | **جديد** |
| `src/app/(shop)/error.tsx` | **جديد** |
| `src/app/(shop)/layout.tsx` | يستبدل الموجود (إضافة سطرين لـ ChunkGuard فقط) |
| `src/components/shop/ChunkGuard.tsx` | **جديد** |
| `src/components/shop/inventory/` (كل المجلد) | يستبدل الموجود |

### بالأوامر (من جذر المشروع):
```bash
# من داخل مجلد patch-v14
xcopy /E /Y src "D:\mobile-shop\src\"
```
أو يدويًا: انسخ الملفات على نفس المسارات.

**مفيش** packages جديدة، **مفيش** تغييرات قاعدة بيانات، **مفيش** تعديل على إعدادات
Cloudflare — ارفع واعمل push وهيتبني تلقائي بنفس `npm run cf:build`.

بعد النشر: افتح الموقع على الموبايل **اعمل تحديث صفحة واحد** (أو هيحصل تلقائي بفضل
ChunkGuard) عشان المتصفح يسحب النسخة الجديدة.
