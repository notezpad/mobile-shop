# نظام المحل — PATCH v12: دليل الاستخدام التفاعلي 📖✨

## إيه الجديد؟

إعادة تصميم كاملة لصفحة **دليل الاستخدام** (`/guide`) — من «كتاب طويل ممل» إلى **تجربة تفاعلية سريعة**:

1. **«ابدأ في 5 دقائق»** — 4 بطاقات سريعة (سجّل دخول → أضف منتج → بيع → تابع أرقامك)،
   ودوس على أي واحدة توديك جوه الجولة عند الخطوة المعنية.
2. **مشغّل جولة تفاعلي** — بدل 16 خطوة ورا بعض في سكرول لا نهائي:
   - شاشة واحدة قدامك في كل مرة + شريط تقدم + عداد «3 / 16»
   - أزرار السابق/التالي + **أسهم الكيبورد** (شمال = التالي، يمين = السابق)
   - شريط chips فيه كل الصفحات — دوس على أي صفحة تقفز لها
   - نقاط progress أسفل + الشرح الطويل بقى مطوي ورا «الشرح الكامل للشاشة دي»
3. **الميزات الذكية** — بقت أكورديون: الصور ظاهرة على طول، والشرح التفصيلي ورا «التفاصيل».
4. **جدول الباقات اتنقل من الدليل** — مكانه شريط واحد أنيق يوديك لصفحة الأسعار `/pricing`
   (الجدول الكامل لسه موجود هناك زي ما هو).
5. **ملابس وأحذية** — الفقرات الطويلة بقوا نقطتين قصيرين + نفس الصور الأربعة.

> **صفر فقدان محتوى**: كل النصوص الأصلية موجودة — بس بنعرضها لما المستخدم يطلبها
> (Progressive Disclosure) بدل ما نرميها في وشه من أول ثانية.

## الملفات المتغيرة (3 ملفات بس — كلها جوه مجلد الدليل)

```
src/app/guide/page.tsx        ← الصفحة (إعادة كتابة)
src/app/guide/guide-data.tsx  ← المحتوى (سطر ملخص لكل خطوة + نقل الباقات)
src/app/guide/guide.css       ← طبقة أنماط جديدة تحت (القديم كله زي ما هو)
```

## طريقة التركيب (دقيقتين)

1. افتح مجلد المشروع عندك (مثلاً `D:\mobile-shop`)
2. انسخ مجلد `src/app/guide/` من الحزمة دي **فوق** الموجود (استبدال للملفات الثلاثة)
3. اعمل Commit و Push من GitHub Desktop زي كل مرة
4. Cloudflare هيبني وينشر لوحده — **مش محتاج أي أوامر ولا مكتبات جديدة**
   (ومع إصلاح v11، خطوة كاش الصفحات هتشتغل لوحدها والصفحة هتتقدم جاهزة وسريعة)

## ملاحظات فنية

- الصفحة لسه `'use client'` بدون أي استدعاءات سيرفر → بتفضل قابلة للـ prerender
  → بتدخل في كاش الصفحات الثابت (v11) → CPU ~صفر زي باقي الصفحات.
- مفيش أي تغيير على قاعدة البيانات أو الـ APIs أو أي صفحة تانية.
- صور الدليل الـ 42 نفسها زي ما هي — مفيش ملفات صور جديدة ولا اتشالت صور.
- متوافق مع الموبايل (chips بتتسكرول أفقي، الأزرار بتمتد، الصور بترص عمود واحد).
