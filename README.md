# 📦 تحديث v19 — إصلاح كارت مسار الشحنة وبوليصة الشحن على الجوال

## المشكلة اللي اتصلحت (بلاغك بالحرف)
> «لما بختار فرع بلاقي كارت مسار الشحنة زاد ضعف عرضه ونصه خارج شاية الموبايل
> وكارت بوليصة الشحن اللي تحته بردو، باقي الصفحة مفيهاش أي مشكلة»

**السبب الجذري:** في CSS Grid، العمود المكتوب `1fr` معناه `minmax(auto, 1fr)` —
والـ auto-min بيمنع العمود من النكواش تحت عرض أطول كلمة في اسم الفرع المختار.
مع أسماء فروع حقيقية، جريد المسار بياخد **401px داخل شاشة 360px** → كارت
«مسار الشحنة» وكارت «بوليصة تحويل» بيطلعوا **435px** والنص قاطع بره الشاشة.
وكمان المسار الأوسط بين الفرعين (`minmax(2.5rem,0.8fr)`) كان بياخد ~120px من
المساحة ويسحق عقدتي الفرع لعمود كلمة-كلمة.

## الإصلاح (ملف واحد)
`src/components/shop/inventory/TransfersTab.tsx`:
1. أعمدة الفرعين بقت `minmax(0,1fr)` — تنكمش لأي عرض واسم الفرع يلف لسطرين
   بشكل نظيف بدل ما يوسّع الكارت بره الشاشة
2. المسار الأوسط على الجوال بقا عرض ثابت صغير (2.5rem) — وعلى الشاشات الكبيرة
   (sm+) يفضل عريض زي ما كان بالظبط (0.8fr)
3. `overflow-hidden` على خط المسار + `min-w-0` على عقدة الفرع والاسم المختار —
   عشان أي عنصر داخلي يقدر ينكمش ومفيش حاجة تكسر العرض تاني
4. الجريد الخارجي (المسار + البوليصة) بقا `grid-cols-1` على الجوال — حماية
   إضافية إن الكارتين ميفيضوش عن الشاشة مهما حصل
5. نفس العلاج اتنقل لكارت الشحنة المصغّر في الأرشيف ودياولوج تفاصيل الشحنة
