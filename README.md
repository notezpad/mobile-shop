# nezampos — PATCH v16 (إصلاح نهائي لشاشة الحركات السوداء)

## المشكلة اللي بتحلها
صفحة الحركات (`/inventory/movements`) بتظهر ~3 ثواني وبعدها شاشة الخطأ/السوداء،
وخطأ الكونسول: `TypeError: Cannot read properties of undefined (reading 'toLocaleString')`.

**السبب الجذري:** دالة تنسيق الأرقام `num()` كانت بتعمل `n.toLocaleString()` مباشرة
على أي قيمة جاية من الـ API — لو الرد وصل بشكل غير متوقع (object خطأ بحالة 200،
قيمة ناقصة، رقم متسلسل كنص…) القيمة بتكون `undefined` فبتقصف الصفحة كلها بعد
ما البيانات توصل (بالظبط بعد الـ 3 ثواني اللي بتشوفها الصفحة شغالة).

## الإصلاح (6 ملفات — كلها في مجلد واحد، استبدال مباشر)
1. **shared.tsx** — `num()` بقيت محصّنة: أي قيمة غريبة/ناقصة بتترجّع 0 بدل ما تكسّر
   الصفحة، و`Signed` (الأرقام بالإشارة) اتحصّن بنفس الطريقة. ده بيقتل نوع الخطأ ده
   في الصفحات الأربعة كلها (المخزون/الحركات/التحويلات/الجرد) من مكان واحد.
2. **useInventoryData.ts** — كل الـ APIs بتتراج قبل عرضها: أي رد مش مصفوفة
   بيتعامل كقائمة فاضية، وعناصر التحويلات/الجرد بتتأكد إن `items` فيها مصفوفة.
3. **MovementsTab.tsx** — رد البحث/الفلاتر المباشر بيتحقق منه كمان.
4. **MovementsPage.tsx** + **TransfersPage.tsx** — حماية عمود «المنتج/الفروع» في
   تصدير Excel من الصفوف الناقصة.
5. **InventoryView.tsx** — نفس حماية المصفوفات في الكود القديم المشترك.

## إزاي تركّبها
1. انسخ مجلد `src` اللي في الحزمة فوق مشروعك (استبدال مباشر لنفس الملفات).
2. اعمل push — Cloudflare هيبني لوحده (مفيش deps جديدة ولا تغيير قاعدة بيانات).
3. بعد النشر اعمل تحديث صفحة واحدة (hard refresh) ولو ظهرت رسالة
   «اتنشرت نسخة جديدة» اضغط تحديث — ده طبيعي مرة واحدة بس.

## إثبات الإصلاح (27/27 ✅)
- ردّ الـ API القاتل القديم (200 + object خطأ): الصفحة فضلت شغالة والعدّاد ظهر 0 —
  نفس السيناريو اللي كان بيჸمنّي الشاشة السوداء.
- صفوف عدوانية (منتج محذوف null، كمية كنص «7»، كمية null): اترسمت كلها من غير أي خطأ.
- ثبات 15 ثانية على موبايل 360px مع API متأخر 2 ثانية: مفيش شاشة خطأ.
- صفر أخطاء JS وصفر فيض أفقي على الموبايل والديسكتوب في الصفحات الأربعة.
- كروت منتجات المخزون على الجوال بنمط «التسمية فوق والقيمة تحت» زي ما طلبت،
  والمبالغ المليونية (638,992,226 جنيه) ظاهرة كاملة في الهيرو والكروت.
