  حزمة إصلاح الأوفلاين v4 — نظام المحل (2026-10-07)

(v3 اشتغلت ممتاز — دي بتكمل باقي الشاشات: المخزون والحركات والجرد والإعدادات)

── اللي اتصلح في v4 ──

  1) المخزون أوفلاين كان بيفتح بصفر + بانر أحمر "الخطأ: رمز 503":
     صفحات المخزون (والحركات والجرد والتحويلات) بتقرأ بياناتها بـ fetch
     خام مباشر — مش من طبقة الكاش بتاعة التطبيق. دلوقتي ردود الـ API
     بتتخزن في كاش الـ Service Worker نفسه (9 endpoints منهم كل مخزون)،
     فأوفلاين بترجع بياناتها فوراً من غير 503.

  2) باقي الصفحات "مش بتفتح أو مفيش استجابة":
     التسخين المسبق بقى يغطي كل شاشات النظام (21 صفحة) — شاملة
     /settings و/branches و/users و/maintenance وصفحات المخزون الفرعية
     (حالة المخزون/الحركات/الجرد) و/الإرشاد. أي لينك في القايمة هيفتح أوفلاين.

  3) بعد أي نشر جديد: الكاش بيتفرغ تلقائياً (ده طبيعي في الـ SW) —
     دلوقتي النظام بيكتشف التحديث بيعيد التسخين الكامل لوحده فوراً،
     مش بعد 20 دقيقة زي قبل كده. يعني مفيش "أوفلاين فاضي" بعد أي تحديث.

  4) خصوصية الجهاز المشترك: عند تسجيل الخروج ردود الـ API المخزنة
     بتتمسح من كاش الـ SW — مفيش مستخدم تاني يشوف بيانات حساب قديم أوفلاين.

── الملفات الـ 3 (فك الضغط فوق مجلد المشروع جوار package.json) ──

── خطوات التركيب ──

  1) فك الضغط فوق مجلد المشروع (المجلد اللي فيه package.json)
  2) git add . && git commit -m "PWA offline fix v4 - inventory + all pages" && git push
  3) انتظر بناء Cloudflare يخلص أخضر (تم التحقق ببناء حقيقي كامل: نجح + 37/37 صفحة)
  4) افتح الموقع وأنت متصل + اعمل Ctrl+Shift+R مرة واحدة
  5) استنى 30-60 ثانية وأنت متصل (التسخين التلقائي بيشتغل في الخلفية
     بيسخّن 21 صفحة + كل بيانات المخزون) — ممكن تتصفح المخزون والحركات
     صفحة صفحة وأنت متصل عشان تخزن أحدث أرقام
  6) افصل النت وجرّب

── اختبارات التحقق (أنت أوفلاين) ──

  ✅ المخزون → يعرض الأصناف والقيم الحقيقية (مش صفر) ومن غير بانر 503
  ✅ حالة المخزون / الحركات / الجرد / التحويلات → كلها تفتح ببياناتها
  ✅ الإعدادات / الفروع / المستخدمين / الصيانة → تفتح من الكاش
  ✅ سجل خروج ثم دخول بحساب تاني → مفيش بيانات الحساب القديم أوفلاين
  ✅ البيع أوفلاين لسه شغال برسالة خضراء (زي v3)
