────────────────────────────────────────────────────────────────────
■ ما الذي أُصلح في v5؟
────────────────────────────────────────────────────────────────────

① صفحات (الجرد / التحويلات / الخزنة / التقارير / الإعدادات) أوفلاين
   كانت تعطي "خطأ غير متوقع":
   السبب الجذري: صفحات التطبيق بتستخدم next/dynamic — كود الصفحة بيتحمّل
   في ملفات chunks منفصلة وقت فتحها. تسخين v4 كان بيخزّن HTML الصفحات
   فقط، فأي صفحة ما اتفتحتش أونلاين بعد آخر تحديث للنظام كانت chunks
   بتاعتها مش متخزنة → أوفلاين بيفشل التحميل → صفحة الخطأ.
   الحل (sw.js v10): بعد تسخين أي صفحة، النظام بيمشي على "جراف" الملفات
   تلقائياً (HTML → السكربتات → الـ chunks المضمّنة جواها وهم بشكل متكرر)
   ويخزّنهم كلهم — فأي صفحة من قايمة النظام تفتح أوفلاين كاملة.

② البحث في المنتجات أوفلاين كان يقول "أنت غير متصل بالإنترنت"
   (نقطة البيع + صفحة المنتجات + أمر الشراء):
   السبب الجذري: جدول المنتجات المحلي (IndexedDB) كان بيفضل فاضي!
   السيرفر بيرجع المنتجات داخل ظرف { data, ... } والكود القديم كان
   مستني قائمة مباشرة، فشرط التخزين كان بيفشل دايماً بصمت.
   الحل: التخزين اتصحّح (وبيرقّم الصفحات لحد ما يسحب كل المنتجات)،
   والبحث المحلي بقى مطابقة جزئية زي السيرفر بالظبط (أي كلمة في نص
   الاسم أو الباركود مش من البداية بس).

③ البيانات المضافة أوفلاين كانت مش بتظهر (زي منتج ضفته أوفلاين):
   الحل: أي منتج بتضيفه أوفلاين بيظهر فوراً في القوائم والبحث
   (معلم بـ id محلي مؤقت)، ولما النت يرجع والمزامنة تعمل المنتج
   على السيرفر بيتسجّل بالـ id الحقيقي — حتى فاتورة بيع بيعت منتج
   أُضيف أوفلاين بتتشاور على المنتج الصح بعد المزامنة ومفيش فاتورة بتضيع.

④ التقارير والإعدادات أوفلاين كانت بترمي أخطاء أحمر:
   الحل: أي واجهة بتتغير query بتاعها (تواريخ التقارير، فلاتر الفروع،
   إشعارات...) أوفلاين بترجع آخر نسخة معروفة من نفس الواجهة بدل خطأ،
   وكمان البحث في العملاء والموردين أوفلاين بقى بيفلتر آخر قائمة معروفة.

⑤ فولباك الشبكة الإضافي في الـ Service Worker:
   أي طلب API أوفلاين بنفس المسار بأي فلاتر مختلفة بيرجع آخر نسخة
   مخزّنة بدل 503 — فصفحات المخزون والحركات مع الفلاتر ما بترمش أخطاء.

────────────────────────────────────────────────────────────────────
■ طريقة التركيب:
────────────────────────────────────────────────────────────────────
 1) فك الضغط واستبدل الملفات الخمسة بنفس المسارات.
 2) npm run cf:build
 3) ارفع (deploy) كالمعتاد.
 4) على الجهاز: افتح التطبيق أونلاين مرة واحدة وسيبه دقيقة —
    هتلاقي في الخلفية تنزيل مرة واحدة لتطبيق الشاشات (~3-5 ميجا)
    وبعدها كل الصفحات بتشتغل أوفلاين، حتى اللي عمرك ما فتحتها.

■ ملاحظات:
 - "منتجات اليوم المعلّقة" في أمر الشراء أوفلاين بتظهر من آخر نسخة
   معروفة — افتح أمر الشراء مرة واحدة وأنت متصل عشان تتخزن.
 - علامة النجاح: قطع النت → افتح الجرد/التحويلات/الخزنة/التقارير/
   الإعدادات → كلها تفتح بآخر بيانات من غير بانر أحمر.
 - لو ظهرت رسالة "أنت غير متصل" لأول مرة على صفحة معينة: افتح الصفحة
   مرة واحدة وأنت متصل لتخزين بياناتها أول مرة.
