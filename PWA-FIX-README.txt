==============================================
الملفات المصلحة - إصلاح PWA أوفلاين (آخر جلسة فقط)
==============================================

هذا الملف يحتوي على 5 ملفات فقط هي اللي اتعدلت في آخر جلسة
لإصلاح مشكلة PWA في وضع عدم الاتصال — مش المشروع كله.

------------------------------------------------
طريقة التركيب:
------------------------------------------------
1) فك ضغط الملف ده فوق مجلد المشروع الرئيسي
   (نفس المجلد اللي فيه package.json)
   - الملفات هتتحط في مكانها الصح وتستبدل القديم تلقائيًا

2) ارفع على Cloudflare واعمل deploy بالطريقة المعتادة
   (Build command زي ما هو: npm run cf:build)

3) بعد النشر: افتح الموقع مرة واحدة وأنت متصل بالإنترنت
   - ده مهم عشان Service Worker v7 يتثبت
   - وكمان عشان الجلسة تتحفظ على الجهاز (IndexedDB)

4) افصل النت وجرّب:
   - فتح التطبيق من PWA
   - عمل Refresh للصفحة
   - تسجيل الدخول
   كل ده المفروض يشتغل أوفلاين من غير ما يرجعك للرئيسية

------------------------------------------------
الملفات الخمسة المصلحة:
------------------------------------------------
1) public/sw.js
   Service Worker v7 (OFFLINE-PROOF) — الإصلاح الرئيسي:
   - إصلاح فشل التشغيل مع ?source=pwa (ignoreSearch)
   - سلسلة رجوع 5 مستويات للأوفلاين (مستحيل يرجع صفحة فاضية)
   - الكاش بقى متسامح (مش فاشل كله لو ملف واحد ناقص)

2) public/offline.html
   صفحة الأوفلاين + زر "فتح النظام" يرجعك للداشبورد

3) src/lib/auth-client.ts
   - حفظ الجلسة تلقائيًا في IndexedDB أول ما تحمل
   - لما النت يفصل ب يقرأ الجلسة المحفوظة (صلاحية 14 يوم)
   - لو الرد الحقيقي "مش مسجل" بيمسح الجلسة (أمان الأجهزة المشتركة)

4) src/lib/offline/prewarm.ts
   تسخين الكاش مسبقًا لصفحات: login / dashboard / pos /
   products / sales / customers / inventory + /api/auth/me

5) src/components/shop/OfflineIndicator.tsx
   شريط التنبيه أوفلاين برسالة صحيحة
   ("التطبيق شغّال ببيانات جهازك")
